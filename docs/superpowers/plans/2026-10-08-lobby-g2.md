# G2: 로비 확장(주간 스텝 오퍼 · 데일리 리워드 · 윈 스트릭 프리플레이) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bounce 로비를 sf 구성에 맞춘다. 홈은 기존 stage_slot 경로를 유지하고, 오프라인 자리표시자였던 스텝 오퍼를 F1의 `StepOffers`(주간 로테이션)로 교체하며, 데일리 리워드 팝업과 윈 스트릭 프리플레이 팝업을 BK.UI 위에 새로 만든다.

**Architecture:** 데이터/규칙은 전부 BK.Meta(F1)에 있다. 게임은 카탈로그 3종(`BounceStepOffers`, `BounceDailyRewards`, `BounceWinStreak`)을 `MetaInstaller`에 넘기고, `KitApp`이 파사드로 노출한다. 새 팝업 2종은 `UIViewBase` 파생 + 코드 생성 프리팹(`BK > Integration > Generate Bounce UI Prefabs`, Addressables 그룹 `Bounce Integration`, 주소 `Bounce/UI/<Name>`)이고 `IUIService.OpenAsync`로 Popup 레이어에 뜬다(딤 자동). 임포트된 엔드리스 오퍼 팝업 프리팹은 그대로 쓰되 바인딩만 `StepOffers`로 바꾼다.

**sf 조사 결과(권위, `D:\ngfe_sf`):**
- 로비 = HUD(골드/하트/설정/프로필/탭) + 3페이지 페이저(Store/Home/Content). 홈 측면 아이콘은 엔드리스 오퍼·패스·피기·윈타워·노애즈·웰컴딜. 이 중 Bounce는 엔드리스 오퍼(+웰컴딜 표시용)만 쓴다.
- 엔드리스 오퍼: 한 주에 한 타입만 활성(짝수 주 체인 7슬롯, 홀수 주 수직 4슬롯). 로비 아이콘은 남은 시간 + 레드닷(현재 스텝이 무료일 때). 지난 스텝은 그리지 않고 현재 스텝부터 창을 보여준다. 무료 스텝은 advance → 지급, 보상 팝업 없음. 유료 스텝은 스토어 → 성공 시 advance(Bounce는 결제 미연결 안내만).
- 데일리 리워드: sf 본 게임은 미연결(템플릿만). 템플릿 규칙 = 7일 순환 + 보너스 3슬롯 + 시간당 무료 코인, 레드닷 수 = 받을 수 있는 수. 그대로 BK.Meta `DailyRewards`가 구현돼 있다.
- 윈 스트릭: 로비 게이지 없음. Play 버튼이 프리플레이 팝업(`popup_winstreak`)을 열고, 거기에 연승 게이지(캡 10, 마일스톤 3/5/10)·마일스톤 보상·진입 부스터 슬롯·Play 버튼이 있다. 보상은 다음 판의 진입 부스터.
- 설정/상점: 이미 임포트된 sf 프리팹을 쓰고 있어 구조가 같다. 이번 범위에서 손대지 않는다.

**가정(사용자 부재 중 결정):**
- 결제는 여전히 미연결. 유료 스텝/상점 카드는 안내 메시지만 띄운다(`ConfirmPaid` 훅은 남긴다).
- 오프라인 `OfferCatalog`/`BounceOfferData`/`OfferClaim`/`IOfferSource`는 `StepOffers`로 대체되므로 삭제한다(관련 테스트는 새 흐름으로 재작성).
- 윈 스트릭 보상은 다음 `Play` 시 지갑에 부스터로 지급한다(sf의 "진입 부스터"를 Bounce 인벤토리로 단순화).
- 주차 epoch = 2026-01-05 00:00 UTC(월요일). 스텝 오퍼 언락 스테이지 = 2, 윈 스트릭 언락 스테이지 = 1.
