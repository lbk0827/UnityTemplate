# 툴링: 테이블 익스포터 · 범용 에디터 툴 · 규약 테스트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (1) sf TableExporter(4.3k줄 Tkinter GUI, DUG `KeyValueTable` 출력)를 BK.Data의 `TableAsset<K,Row>` 형식에 맞춘 **작은 CLI**(`tools/tables/export_tables.py`)와 **범용 Unity 임포터**(`BK > Data > Import Tables`)로 대체한다. xlsx 헤더 문법은 sf와 호환(행2 `#data`+컬럼명, 행3 타입/옵션, 행4 export 마커, 행5부터 데이터). (2) sf RootBox의 의존성 없는 에디터 툴 4종(AssetDefFinder, NestedPrefabFinder, ComponentReplaceTool, PrefabCleanupTool)을 `BK.Editor`로 이식한다. (3) 아키텍처 규약을 EditMode 테스트로 고정한다(sf의 `*ContractTests` 패턴).

**Architecture:** 익스포터는 Python + openpyxl(설치 확인됨 3.1.5), 입력 폴더의 `*.xlsx`마다 시트별로 `<Sheet>Row`/`<Sheet>Table` C#과 `{"_rows":[...]}` JSON을 쓴다. Unity 임포터는 JSON 옆의 같은 이름 `TableAsset` 서브클래스를 리플렉션으로 찾아 `_rows`를 채우고(.asset 생성/갱신), Addressables 그룹 `BK Tables`에 `Data/Tables/<Name>` 주소로 등록한 뒤 `TableCatalog`에 추가한다. 에디터 툴은 네임스페이스만 `BK.Editor.Tools`로 바꾸고 메뉴를 `BK/Tools/...`로 옮긴다. 규약 테스트는 소스 grep과 asmdef 그래프 검사.

**Tech Stack:** Python 3.14 + openpyxl, Unity Editor API(PrefabUtility, AddressableAssetSettings), NUnit.

**사전 확인된 사실:**
- sf 헤더 문법(`__TABLE_SCRIPT__.py` 395–480): 행1 `[0]`=서브폴더(옵션), 행2 `[0]`=`#data`, 행2 컬럼명(`Name[]` 접미사=배열), 행3 타입/옵션 콤마 리스트(`key`, `int|long|float|double|bool|string|localtext|stream`, `origin`, `unique`, `null`, `check<sheet/col>`, `type<ENUM>`, `typeref<Enum>`), 행4 export 마커(`data`), 행3 `[0]`에 `nocode`/`valueonly` 옵션. 본 CLI는 `key`, 기본 타입 7종, 배열 접미사, `type<ENUM>`(열거형 생성), `unique`만 지원하고 `check<>`/`localtext`/`stream`/`valueonly`/`#merge`는 **경고 후 무시**한다.
- BK.Data: `TableAsset<TKey,TRow>`의 `[SerializeField] List<TRow> _rows`, `TRow : ITableRow<TKey>` (`TKey Id {get;}`), `TableCatalog._addresses`. Bounce의 `ShopTableImporter`가 리플렉션으로 `_rows`를 채우는 선례.
- 기존 JSON 포맷은 `{"_rows":[...]}` (JsonUtility 래퍼).
- sf 툴 4종: 네임스페이스 `RootBoxEditor`, 메뉴 `RootBox/Tools/...`, 의존은 `UnityEditorInternal`/UIElements뿐. `NestedPrefabFinder.cs`의 `using UnityEditor.Experimental.SceneManagement;`는 Unity 6에서 제거 대상(PrefabStageUtility는 `UnityEditor.SceneManagement`).
- 현재 테스트: EditMode 78, PlayMode 12.

**Files:**
- Create: `Assets/BKFramework/Tests/EditMode/ArchitectureConventionTests.cs`

```csharp
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text.RegularExpressions;
using NUnit.Framework;
using UnityEngine;

namespace BK.Tests
{
    /// <summary>Source-level guards for rules that no compiler enforces (sf's *ContractTests pattern).</summary>
    public sealed class ArchitectureConventionTests
    {
        private static readonly string Root = Path.Combine(Application.dataPath, "BKFramework", "Runtime");

        private static IEnumerable<string> RuntimeSources() => Directory.EnumerateFiles(Root, "*.cs", SearchOption.AllDirectories);

        [Test]
        public void OnlyBackInputDriverReadsTheEscapeKey()
        {
            var offenders = RuntimeSources().Concat(Directory.EnumerateFiles(Path.Combine(Application.dataPath, "_Project"), "*.cs", SearchOption.AllDirectories))
                .Where(f => !f.EndsWith("BackInputDriver.cs"))
                .Where(f => Regex.IsMatch(File.ReadAllText(f), @"KeyCode\.Escape|escapeKey"))
                .Select(f => Path.GetRelativePath(Application.dataPath, f)).ToList();
            Assert.That(offenders, Is.Empty, "route back input through IUIService.HandleBackRequest");
        }

        [Test]
        public void FrameworkNeverReadsTheSystemClockDirectly()
        {
            var offenders = RuntimeSources()
                .Where(f => !f.EndsWith("SystemClock.cs") && !f.EndsWith("SaveFile.cs"))
                .Where(f => Regex.IsMatch(File.ReadAllText(f), @"DateTime\.(UtcNow|Now)\b"))
                .Select(f => Path.GetRelativePath(Application.dataPath, f)).ToList();
            Assert.That(offenders, Is.Empty, "inject IClock");
        }

        [Test]
        public void FrameworkAssembliesOnlyDependDownward()
        {
            var allowed = new Dictionary<string, string[]>
            {
                ["BK.Core"] = new string[0],
                ["BK.Save"] = new[] { "BK.Core" },
                ["BK.Options"] = new[] { "BK.Core", "BK.Save" },
                ["BK.Meta"] = new[] { "BK.Core", "BK.Save" },
                ["BK.Assets"] = new[] { "BK.Core" },
                ["BK.Scene"] = new[] { "BK.Core", "BK.Assets" },
                ["BK.Data"] = new[] { "BK.Core", "BK.Assets" },
                ["BK.UI"] = new[] { "BK.Core", "BK.Assets", "BK.Scene" },
                ["BK.Localization"] = new[] { "BK.Core", "BK.Assets", "BK.Data" },
                ["BK.Presentation"] = new[] { "BK.Core" },
            };
            foreach (var asmdef in Directory.EnumerateFiles(Root, "*.asmdef", SearchOption.AllDirectories))
            {
                var json = JsonUtility.FromJson<AsmdefProbe>(File.ReadAllText(asmdef));
                if (json.name == "BK.Composition") continue; // the root may see everything
                Assert.That(allowed.ContainsKey(json.name), Is.True, $"{json.name} is not in the layer map; add it with its allowed references");
                var bad = json.references.Where(r => r.StartsWith("BK.") && !allowed[json.name].Contains(r)).ToList();
                Assert.That(bad, Is.Empty, $"{json.name} references {string.Join(", ", bad)}");
            }
        }

        [System.Serializable] private sealed class AsmdefProbe { public string name; public string[] references = new string[0]; }
    }
}
```

`SaveFile.cs`는 파손 파일 보존 이름에 `DateTime.UtcNow`를 쓰므로 예외. `_Project`(Bounce)에서 Escape 폴링이 남아 있으면 이 테스트가 잡는다(현재는 제거됨).

CLI 사양:

```
python -I tools/tables/export_tables.py --xlsx <dir|file> --json-out Assets/_Project/Data/Tables/Generated --cs-out Assets/_Project/Scripts/Tables/Generated --namespace Project.Tables [--write-sample path]
```

- 시트 처리: 행2 `[0]`이 `#data`인 시트만. 컬럼: 행2 이름(끝 `[]`=배열), 행3 옵션 콤마 리스트, 행4가 `data`가 아닌 컬럼은 제외. 데이터는 행5부터, 첫 셀이 비면 종료.
- 타입: `int,long,float,double,bool,string` + `type<NAME>`(C# enum `NAME` 생성, 값은 시트 `types`의 `NAME` 컬럼 목록 또는 데이터에서 수집한 문자열을 순서대로 0..n). 배열 셀은 콤마 분리. `key`는 정확히 한 컬럼, 타입은 int 또는 string.
- 출력 JSON: `{"_rows":[{col:value,...}]}` 들여쓰기 2, 키 순서 = 컬럼 순서. enum은 정수로 기록(JsonUtility가 enum을 int로 읽음).
- 출력 C#: 
  ```csharp
  // <auto-generated> export_tables.py — do not edit
  using System; using BK.Data; using UnityEngine;
  namespace <ns> {
      [Serializable] public sealed class XxxRow : ITableRow<int> { public int id; ...; public int Id => id; }
      [CreateAssetMenu(menuName = "BK/Tables/Xxx")] public sealed class XxxTable : TableAsset<int, XxxRow> { }
  }
  ```
  키 컬럼의 C# 필드명은 그대로 두고 `Id` 프로퍼티가 그것을 돌려준다. 컬럼명은 C# 식별자 검증(정규식 `^[A-Za-z_][A-Za-z0-9_]*$`), 예약어면 `@` 접두.
- enum 파일: `<ns>/TableEnums.cs` 하나에 모든 `type<>` 열거형.
- 검증: 중복 키 → 에러(종료 코드 1), 타입 변환 실패 → 셀 좌표와 함께 에러, `unique` 컬럼 중복 → 에러. 미지원 옵션(`check<>`, `localtext`, `stream`, `valueonly`, `nocode`)은 경고 1줄 후 무시.
- `--write-sample`: 2시트(`Stage`: key int `id`, `int reward`, `string[] tags`, `type<DIFFICULTY> difficulty`; `types` 시트 `DIFFICULTY: EASY,NORMAL,HARD`) xlsx 생성. README에 헤더 문법 표.

unittest: 샘플을 임시 폴더에 쓰고 export → JSON 파싱해 `_rows[0].tags == ["a","b"]`, `difficulty == 2`, C# 파일에 `class StageRow : ITableRow<int>`와 `enum DIFFICULTY` 존재, 중복 키 xlsx는 exit 1.

API:

```csharp
namespace BK.Editor
{
    public static class TableImporter
    {
        public const string GroupName = "BK Tables";
        /// <summary>Fills every TableAsset subtype whose name matches a JSON next to it. Returns imported asset paths.</summary>
        public static IReadOnlyList<string> ImportFolder(string jsonFolder, string assetFolder, bool registerAddressables = true, string catalogPath = null);
        [MenuItem("BK/Data/Import Tables")] public static void ImportProjectTables(); // FrameworkSettings 없이 고정 경로: Assets/_Project/Data/Tables/Generated → Assets/_Project/Data/Tables, catalog Assets/_Project/Data/TableCatalog.asset
    }
}
```

구현 요점: `TypeCache.GetTypesDerivedFrom<TableAsset>()`에서 이름이 `<JsonName>` 또는 `<JsonName>Table`인 타입을 찾는다. `_rows` 채우기: `JsonUtility.FromJson(json, wrapperType)`을 위해 제네릭 `Wrapper<TRow>{ public List<TRow> _rows; }`를 `MakeGenericType`으로 만들고 `TableAsset<,>`의 `_rows` 필드에 `SetValue`. 에셋이 없으면 `CreateAsset`, 있으면 `CopySerialized` 후 `SetDirty`. Addressables: `registerAddressables`가 true이고 설정이 있으면 그룹 `BK Tables`에 주소 `Data/Tables/<Name>`; `catalogPath`가 있으면 `TableCatalog._addresses`에 없을 때 추가(`SerializedObject`로 편집).

테스트: 임시 폴더 `Assets/BKFramework/Tests/EditMode/__tmp_tables/`에 `Probe.json`(`{"_rows":[{"id":1,"name":"a"},{"id":2,"name":"b"}]}`) 작성 → `ImportFolder(tmp, tmp, registerAddressables:false)` → 로드한 `ProbeTable.Get(2).name == "b"`, `Count == 2` → 폴더 삭제(`AssetDatabase.DeleteAsset`).
