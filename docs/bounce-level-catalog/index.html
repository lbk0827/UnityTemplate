BOUNCE / LEVEL DESIGN

레벨 카탈로그

배치와 기믹부터 탄 여유, 실제 클리어 경로까지.

출시 캠페인 140레벨 · 35가지 사물 도안. 1~13은 일반 블록. 기뢰 14 → 금속관 21 → 찬장 41 → 이동 패널 61 → 스위치·문 81 → 방향 장갑 101 → 연속 타격 121. 해금된 기믹은 재사용·혼합합니다. 140 이후에는 업데이트를 안내합니다. 외곽 Wall 11×16과 카메라 11.75는 공통이며 내부 배치만 바뀝니다.
검증 이후 게임 소스가 변경되었습니다. 배치 정보는 현재 데이터를 표시하며, 클리어·난도 수치는 재검증 전까지 숨깁니다.

카드의 배치도를 누르면 전체 보드·기믹 좌표·검증 발사 순서를 확대해 볼 수 있습니다. 미리보기는 배치 구간을 확대하므로 카드별 표시 배율이 다릅니다. 일반 블록은 색상과 무관하게 모두 1회 타격으로 제거됩니다.
레벨 상세 · 전체 좌표

실제 스테이지 번호로 찾기

1~140은 각각 고유 배치입니다. 출시 범위 이후에는 도안을 반복하지 않습니다.

난이도와 클리어 가능성 읽는 법

도입 → 복습 → 혼합 → 도전 → 휴식의 설계 역할을 표시합니다. 신규 기믹은 첫 등장과 다음 두 레벨에서 단독 연습합니다. 역할에 따라 실제 검증 경로보다 탄을 더 지급하며, 도전 레벨의 여유를 가장 적게 둡니다.

탄 여유는 검증 경로의 지급 탄 대비 사용 비율입니다. 65% 이하 여유, 80% 이하 보통, 그 이상 빠듯. 최적해나 사람의 성공률을 뜻하지 않습니다.

클리어·재현 확인은 실제 게임의 FixedUpdate를 정상 고정 간격으로 직접 진행하여 모든 목표를 없애고, 동일한 발사 각도와 대기 틱으로 다시 성공했다는 뜻입니다. 부스터·이어하기·직접 피해 주기는 사용하지 않습니다.

첫 기뢰 레벨 14는 일반 속도의 자동 물리 진행으로도 재현합니다. 전체 140개에 대한 수동 플레이·실기기·조준 오차 난이도 평가는 별도이며, 자동 검증을 사람의 성공률로 환산하지 않습니다.

목표 수 = 일반 블록 + 파괴형 기믹 개체 수. 관 조각·찬장 접시 수와는 다릅니다. 이동 패널·스위치·문은 제거 목표가 아닙니다. 보관 레벨은 이번 검증 대상이 아닙니다.

레벨 편집

Unity의 BK Kit → Level Editor에서 이름·설계 의도·지급 탄·내부 Grid 가로(3~11)·세로(8~16)를 변경할 수 있습니다. 1~9 색상으로 블록을 칠하고 저장하세요. 그리드를 줄일 때 잘리는 블록이나 기믹이 있으면 변경을 거부하며, Ctrl+Z로 편집을 되돌릴 수 있습니다.

출시 레벨은 외곽 Wall 11×16, 셀 1유닛, 기준 카메라 Size 11.75를 공유합니다. 내부 Grid 크기나 블록 수로 카메라·Wall·기물 크기가 바뀌지 않습니다. 좁고 긴 화면에서만 좌우 잘림 방지를 위해 배율을 보정합니다. 색상은 내구도와 무관합니다. 기믹의 해금 시점을 어기면 저장을 거부합니다. 원본 도안은 tools/balance/build_release_levels.py에서 관리하며 실행 후 BK Kit → Balance → Apply Release Campaign으로 연결·검증합니다. 재생성은 JSON 수동 편집을 덮어씁니다. 배치가 바뀐 레벨은 이전 탄 보정값을 사용하지 않으므로 해법을 다시 측정하고 보정해야 합니다.

레벨 JSON의 rows는 가로 폭·배치, gridRows는 전체 세로 크기입니다. gridRows가 없는 기존 데이터는 13행 보드로 읽습니다. 배치를 수정한 뒤에는 카탈로그를 다시 생성하고 클리어 검증을 다시 실행해야 합니다.
