레벨 카탈로그

배치와 기믹부터 탄 여유, 실제 클리어 경로까지.

현재는 10개 배치가 반복됩니다. 스테이지 11 → 배치 1, 12 → 배치 2 … 20 → 배치 10. 레벨 숫자에 따른 입장·광고·보상 정책은 별도로 적용됩니다.
검증 이후 게임 소스가 변경되었습니다. 배치 정보는 현재 데이터를 표시하며, 클리어·난도 수치는 재검증 전까지 숨깁니다.

카드의 배치도를 누르면 전체 보드·기믹 좌표·검증 발사 순서를 확대해 볼 수 있습니다. 미리보기는 배치 구간을 확대하므로 카드별 표시 배율이 다릅니다. 일반 블록은 색상과 무관하게 모두 1회 타격으로 제거됩니다.
레벨 상세 · 전체 좌표

실제 스테이지 번호로 찾기

플레이에 사용하는 배치 번호 = ((스테이지 − 1) % 10) + 1

11 → 현재 배치 1

난이도와 클리어 가능성 읽는 법

클리어·재현 확인은 실제 Unity 런타임에서 지급 탄 이내에 모든 목표를 없앤 뒤, 같은 각도 순서로 다시 성공했다는 뜻입니다. 부스터·이어하기·직접 피해 주기는 사용하지 않았습니다. 최소 발사 수를 증명한 최적해는 아닙니다.

탄 여유는 정확한 직선 조준 1회의 탄 소모율입니다. 50% 이하 여유, 50% 초과~75% 보통, 75% 초과 또는 실패 빠듯. 이 카탈로그의 비교 지표이며 게임에 저장된 난이도 등급이 아닙니다.

±2° / ±5°는 기뢰 우선·가까운 목표 중앙을 겨냥하는 봇에 발사마다 독립 균등 오차를 더한 조건입니다. 각 레벨·조건당 회, 오차 0°는 1회입니다. 인간의 성공률이나 초보·고수 등급으로 환산하지 않습니다.

조준 진단과 해법 재현은 시간 배율 12에서 실행했습니다. 고정 물리 간격은 유지하고, 한 공이 끝나기를 기다린 후 다음 공을 쐈습니다. 블록 수 증가가 사람의 체감 난이도를 자동으로 뜻하지는 않습니다. 실제 플레이 난이도는 별도 평가가 필요합니다.

목표 수 = 일반 블록 + 파괴형 기믹 개체 수. 관 조각·찬장 접시 수와는 다릅니다. 이동 패널·스위치·문은 제거 목표가 아닙니다. 보관 레벨은 이번 클리어·조준 진단의 대상이 아닙니다.

레벨 편집

Unity의 BK Kit → Level Editor에서 이름·설계 의도·지급 탄·그리드 가로(3~25)·세로(8~30)를 변경할 수 있습니다. 1~9 색상으로 블록을 칠하고 저장하세요. 그리드를 줄일 때 잘리는 블록이나 기믹이 있으면 변경을 거부하며, Ctrl+Z로 편집을 되돌릴 수 있습니다.

실제 플레이는 그리드 전체가 들어오도록 카메라를 맞춥니다. 넓은 보드에서는 기물이 작게 보이며, 색상은 내구도와 무관합니다. 6번부터 기뢰가 등장하고, 보관 22개 배치의 다른 기믹도 편집기에서 사용할 수 있습니다. 현재 10종 도안을 다시 생성하려면 BK Kit → Balance → Generate Shape Levels 1-10을 사용하세요. 재생성은 현재 적용 JSON의 수동 편집을 덮어씁니다.

레벨 JSON의 rows는 가로 폭·배치, gridRows는 전체 세로 크기입니다. gridRows가 없는 기존 데이터는 13행 보드로 읽습니다. 배치를 수정한 뒤에는 카탈로그를 다시 생성하고 클리어 검증을 다시 실행해야 합니다.
