확인한 것과 남은 것

실제 게임의 발사·반사·기뢰 연쇄·배수·승리 조건으로 부스터 없이 클리어하고, 새 보드에서 같은 각도열을 재실행했습니다. 첫 검증에서 4레벨은 14발 중 12발을 사용해 예산을 18발로 늘렸습니다.

초보·일반·고수 봇 프로필, 조준 오차와 발사 템포, 예비 200~1,000회 및 독립 10,000회 측정은 후속 밸런스 작업입니다. 전부 학습 목표인 이번 10판만으로 D2~D5를 가르는 눈금을 확정하지 않습니다.

프로젝트에서 사용하기

  • 플레이 데이터: Assets/_Project/Bounce/Content/bounce-learning-levels.json
  • Unity 실행(Play) 중 BK Kit → Level Editor에서 1~10레벨을 선택하고 저장하고 플레이. 이 버튼은 로컬 샌드박스 진행도와 부스터 수량을 변경합니다.
  • 동일 시안 재생성: BK Kit → Balance → Generate Learning Levels 1-10. 고정 시드 20261021이며 수동 편집한 학습 데이터를 덮어씁니다.
  • 기존 bounce-levels.json의 22개 배치는 회귀 검사용으로 보존했습니다.
  • 현재 런타임의 순환 규칙을 유지해 11레벨부터 학습 10개 배치가 반복됩니다. 후속 레벨은 별도 제작 대상입니다.
