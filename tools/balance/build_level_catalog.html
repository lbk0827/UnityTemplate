레벨 카탈로그

배치와 기믹부터 탄 여유, 실제 클리어 경로까지.

현재는 10개 배치가 반복됩니다. 스테이지 11 → 배치 1, 12 → 배치 2 … 20 → 배치 10. 레벨 숫자에 따른 입장·광고·보상 정책은 별도로 적용됩니다.
검증 이후 게임 소스가 변경되었습니다. 배치 정보는 현재 데이터를 표시하며, 클리어·난도 수치는 재검증 전까지 숨깁니다.

카드의 배치도를 누르면 전체 보드·기믹 좌표·검증 발사 순서를 확대해 볼 수 있습니다. 미리보기는 배치 구간을 확대하므로 카드별 표시 배율이 다릅니다. 일반 블록은 색상과 무관하게 모두 1회 타격으로 제거됩니다.
레벨 상세 · 전체 좌표

실제 스테이지 번호로 찾기

플레이에 사용하는 배치 번호 = ((스테이지 − 1) % 10) + 1

11 → 현재 배치 1

난이도와 클리어 가능성 읽는 법

클리어·재현 확인은 실제 Unity 런타임에서 지급 탄 이내에 모든 목표를 없앤 뒤, 같은 각도 순서로 다시 성공했다는 뜻입니다. 부스터·이어하기·직접 피해 주기는 사용하지 않았습니다. 최소 발사 수를 증명한 최적해는 아닙니다.

탄 여유는 정확한 직선 조준 1회의 탄 소모율입니다. 50% 이하 여유, 50% 초과~75% 보통, 75% 초과 또는 실패 빠듯. 이 카탈로그의 비교 지표이며 게임에 저장된 난이도 등급이 아닙니다.

±2° / ±5°는 기뢰 우선·가까운 목표 중앙을 겨냥하는 봇에 발사마다 독립 균등 오차를 더한 조건입니다. 각 레벨·조건당 12회, 오차 0°는 1회로 총 250회입니다. 인간의 성공률이나 초보·고수 등급으로 환산하지 않습니다.

정확한 직선 조준은 정상 속도, 오차 실험과 해법 재현은 시간 배율 12에서 실행했습니다. 고정 물리 간격은 유지하고, 한 공이 끝나기를 기다린 후 다음 공을 쐈습니다. 모든 10개 배치의 설계 목표는 학습 D1이며 실측 등급은 미확정입니다.

목표 수 = 일반 블록 + 파괴형 기믹 개체 수. 관 조각·찬장 접시 수와는 다릅니다. 이동 패널·스위치·문은 제거 목표가 아닙니다. 보관 레벨은 이번 클리어·조준 진단의 대상이 아닙니다.
